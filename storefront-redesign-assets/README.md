# FlexMed Storefront Redesign Assets

This folder is a handoff copy of the public storefront image assets used during the redesign pass.

## Folders

- `banners/` - molecule, DNA, lab, hero, and section visuals used for public storefront cards, hero areas, trust sections, and category visuals.
- `logos/` - FlexMed logo files used in the navigation and public homepage hero.

## Source Paths In App

The live app still references the originals in:

- `public/banners/`
- `public/brand/`

These copied files are for design handoff, planning, and easier sharing. Changing files here will not affect the running site unless the app is updated to reference them.
